## Overview
This repository documents a manual sequence analysis investigating how a
documented pathogenic mutation in RB1 (c.373G>T, p.Glu125Ter) disrupts
the RB protein and contributes to retinoblastoma, following the workflow:
DNA mutation → change in coding sequence → change in protein → change in
cellular function → disease phenotype.

A second, self-designed artificial mutation (1-nucleotide deletion) was
also created and compared against the documented mutation to demonstrate
how frameshift vs. nonsense mutations differ in their effects.

## Repository Structure
- `01_reference/` — WT CDS and protein sequences

- `03_artificial_mutation/` — self-designed 1-nt deletion mutant CDS and protein
- `04_results/` — alignment output and summary tables
- `05_report/` — final written report
